# SCimage v1.1.3

本次发布重点收口滚动条显示、图生图族谱切换和发布流程三块体验。版本仍然保持本地工作台的轻量黑色界面风格，但对容易遮挡内容、容易误触的滚动交互做了更明确的分层：数据量大的列表保留可见滚动条，小型面板和横向拖拽区域隐藏滚动条。

## 重点更新

- 重做全局滚动条策略：默认隐藏浏览器原生滚动条，避免小面板、弹窗和横向族谱栏出现多余滚动条或遮挡内容
- 新增统一的 `scrollbar-data` 样式，专门给任务列表、图库窗口、模型列表、提示词列表等大数据滚动区域使用
- 任务列表保留可见滚动条，并改成更细、更暗、更贴边的样式，同时预留右侧空间，减少滚动条压住任务卡片内容的情况
- 图库窗口保留可见滚动条，方便大量图片浏览时判断当前位置；图库内容右侧增加留白，避免滚动条贴住图片网格
- 模型下拉、已保存提示词、内置提示词分类和词组列表统一使用数据滚动条，长列表仍然有明确的位置反馈
- 图生图顶部族谱根图栏继续支持横向拖拽滑动，但隐藏可见滚动条，减少横向条显示异常和遮挡问题
- 修复族谱根图栏点击无法切换的问题：拖拽逻辑只在真正超过拖动阈值后接管指针，普通点击会正常触发族谱切换
- 补充族谱根图栏回归测试，覆盖“拖动可滚动、拖动不误切、点击可切换”三种交互
- 清理发布流程中的重复发布入口：自动打标签后不再额外手动触发桌面发布，统一由版本 tag 触发一次桌面发布
- Release 正文改为读取仓库内版本专属说明文件，避免先自动创建通用说明、再单独补更新说明

## 体验细节

- 任务列表这类高频、大数据区域仍然保留可见滚动条，方便快速判断任务历史位置
- 族谱根图栏、小弹窗内部说明等辅助区域默认隐藏滚动条，让界面更安静，也降低滚动条和内容互相遮挡的概率
- 滚动条样式集中在全局 token 中维护，后续新增列表时只需要按语义选择是否使用 `scrollbar-data`
- 图生图族谱根图栏的拖拽手感保持不变，鼠标拖动仍可横向滑动，触控板横向滚动也继续可用

## 发布流程调整

- 版本号升级到 `1.1.3`
- 自动标签改为唯一语义化标签 `v1.1.3`，如果同名标签已存在会直接失败并提示提升版本号
- 桌面发布仍然产出：
  - `SCimage-windows.zip`
  - `SCimage-macos.zip`
- GitHub Release 创建时会直接使用 `SCimage/docs/releases/v1.1.3.md`，不再生成一份通用说明后再手动补说明
