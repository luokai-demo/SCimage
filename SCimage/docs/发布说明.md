# 发布说明

## 说明

本文档用于整理 `SCimage` 近期版本的重点更新方向，方便查看桌面版发布时到底改了什么。

GitHub Release 页面展示的是发布产物和当次摘要；这里保留更稳定的中文说明。

## 最近更新

### r 系列发布（当前）

本轮发布结构调整与体验修复：

- GitHub 自动 tag 命名从 `build.*` 改为 `r####`
- 同一流水号重发时改为 `-retry.<序号>`，避免旧格式继续累积
- 桌面版下载图片改为优先走原生保存对话框，修复点击下载无反应的问题
- 项目网页角标、桌面打包图标统一改为同一份 `logo.png`

结果：

- Release 命名和排序更稳定
- 桌面版图片下载体验恢复正常
- 网页端和桌面端图标来源统一，后续维护更简单

### v1.0.0-build.11

图库分组能力补齐：

- 图库新增 `提示词` 分组视图
- 同一提示词跨多个任务生成的图片会自动归并到同一组
- 图库会记住上次选择的分组，重开后自动恢复
- 分组状态改为随工作区状态一起落盘，不依赖浏览器本地存储

结果：

- 查看同类提示词产图更直观
- 桌面版和网页开发态重开后分组选择不会丢

### v1.0.0-build.9

计划用于补齐项目文档与发布说明：

- 增加正式的《项目说明》文档
- 增加正式的《发布说明》文档
- 在 `README.md` 中补充文档入口与本地状态文件说明
- 优化 GitHub Release 默认说明模板

### v1.0.0-build.8

发布工作流依赖版本升级：

- `actions/checkout` 升级到 `v6`
- `actions/setup-python` 升级到 `v6`
- `actions/upload-artifact` 升级到 `v6`
- `actions/download-artifact` 升级到 `v5`
- `softprops/action-gh-release` 升级到 `v3`

结果：

- GitHub Actions 发布流程继续可用
- Node 20 退役提示已被清掉

### v1.0.0-build.7

本地状态持久化能力调整：

- 工作区提示词、尺寸、质量、数量、当前工作流改为后端文件持久化
- 默认输出参数尺寸改为 `auto`
- 默认输出参数质量改为 `auto`
- 移除浏览器侧 `localStorage` / `indexedDB` 依赖

结果：

- 桌面包重开后，工作区状态不再丢失

### v1.0.0-build.6

桌面发布稳定性修复：

- macOS runner 调整为 `macos-latest`
- 自动发布链路恢复正常
