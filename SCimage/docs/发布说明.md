# 发布说明

## 说明

本文档用于整理 `SCimage` 近期版本的重点更新方向，方便查看桌面版发布时到底改了什么。

GitHub Release 页面展示的是发布产物和当次摘要；这里保留更稳定的中文说明。

## 最近更新

### v1.1.3（当前）

本轮发布重点收口滚动条显示、图生图族谱切换和发布流程，核心目标是让不同滚动区域按使用场景展示正确的滚动反馈，同时避免发布说明和 Release 正文重复维护：

- 全局滚动条策略改为默认隐藏，减少小面板、弹窗、横向族谱栏中的滚动条显示异常和遮挡问题
- 新增统一 `scrollbar-data` 样式，专门用于任务列表、图库窗口、模型列表、提示词列表等大数据滚动容器
- 任务列表和图库窗口保留可见滚动条，滚动条更细、更暗并预留内容间距，方便大量任务和图片浏览时判断位置
- 模型下拉、已保存提示词、内置提示词分类和词组列表统一使用优化后的可见滚动条
- 图生图顶部族谱栏保留横向拖拽滑动能力，但隐藏可见滚动条，避免横向条遮挡和显示不稳定
- 修复族谱栏普通点击被拖拽逻辑吞掉的问题，只有真正发生拖动时才接管指针
- 补充族谱根图栏浏览器回归测试，覆盖拖动滚动、拖动不误切和点击切换
- 自动发布流程改为只由版本 tag 触发一次桌面发布，Release 正文直接读取版本专属中文说明文件
- 版本号升级到 `1.1.3`，并同步静态构建产物

结果：

- 高频数据列表仍然保留位置感，小型滚动区和横向拖拽区不再出现多余滚动条
- 图生图族谱栏既能拖动滑动，也能稳定点击切换族谱
- GitHub Release 首次创建时就带完整中文更新说明，不再需要发布后单独补说明

### v1.1.2

本轮发布重点收口低清预览移除和 API 配置体验，核心目标是让图库、族谱和模型配置都遵循新的长期数据契约：

- 删除低清占位预览生成、存储、索引和前端渲染链路，图库卡片、族谱根图、族谱节点和灯箱都直接使用最终图片
- 新增图片元数据读取模块，只保留宽高等必要字段；旧的 `preview_url`、`preview`、`placeholder`、占位色字段会在任务记录输出时统一剥离
- 数据库图片索引升级到新结构，启动时会移除旧预览字段并重建索引，生成目录里的历史 `previews/` 子目录也会在清理和删除图片时被顺带移除
- API 配置卡片在已经存在 Base URL、API Key 或模型参数时默认收起，首次无配置时仍自动展开引导填写
- 模型字段从纯下拉改为组合输入框，既支持手动填入模型 ID，也支持拉取 `/models` 后下拉选择
- 模型下拉菜单改为顶层悬浮层，滚动和窗口尺寸变化时自动重新定位，避免被左侧卡片或滚动容器裁剪
- 模型列表不可用时不再显示红色阻断错误；余额不足、权限不足、不支持 `/models` 等情况会显示非阻断提示，并允许继续手动保存模型 ID
- 提供方配置保存不再强制要求模型出现在上游 `/models` 返回列表中，只保留 Base URL 规范化、API Key 继承和必填项校验
- 任务、图库、族谱、模型选择和旧数据迁移相关测试已同步更新，覆盖手动模型、图片模型排序、无预览字段和旧索引迁移路径

结果：

- 图库与族谱不再出现低清占位图导致的模糊根图或模糊卡片
- 对不支持模型发现接口的 API 更友好，用户可以直接输入实际可用的模型 ID
- API 配置区默认状态更安静，不会在已有配置时占用左侧工作区
- 图片记录和前端类型契约更简单，后续维护不再需要同时处理原图、预览图和占位色三套字段

### v1.1.1

本轮发布围绕上线后的结构治理、实时任务体验和图生图工作区稳定性做了一次完整收口：

- 将任务状态刷新从固定轮询升级为服务端推送，任务创建、排队、运行、中断、完成和失败状态能更及时同步到前端
- 按职责拆分后端 `server.py`、任务队列、图库接口、图生图族谱接口、提供方配置接口和维护接口，入口层只保留路由装配
- 拆分图像生成链路中的请求、载荷、传输、响应解析、资产处理和结果落库逻辑，减少重复实现和大文件耦合
- 前端运行时按 API、任务、图库、配置、提示词、工作区状态和运行时事件拆成组合式模块，避免继续把业务逻辑堆进单一运行时文件
- 图生图族谱继续优化为独立工作区，补齐自由画布拖拽、节点位置持久化、血缘关系高亮、节点检查器和小地图导航
- 修复图生图导航小地图黑屏问题，将 SVG 内部图形样式归属到真正渲染节点的子组件，并补充可见节点、连线和视口框回归断言
- 右侧区域重新定义为结果工作区，按当前工作流展示图库或族谱；左侧保持输入工作区，任务队列回到左侧下方默认收起，避免遮挡右侧内容
- 删除任务列表中“失败 / 已完成”等历史分类标题，只保留“进行中”分组，历史任务按时间自然展示
- 继续拆分 Vue 回归测试场景，新增族谱小地图、自由画布拖拽、任务生命周期、视觉回归和发布前校验覆盖
- 补齐隐私字符串扫描、静态产物校验、Python 测试、浏览器 smoke、视觉回归和发布校验脚本，降低发布漏检风险

结果：

- 任务状态反馈更接近实时，长任务和中断操作的反馈更可靠
- 图生图族谱工作区可维护性更好，小地图导航不再出现黑色空面板
- 前后端大文件继续瘦身，新增功能时更容易按稳定职责边界扩展
- 任务列表和左右工作区布局更稳定，展开任务队列不会遮挡结果区域
- 发布链路有更完整的本地校验，静态资源和隐私扫描问题能在发布前暴露

### v1.1.0

本轮发布完成前端技术栈切换与图库、提示词库体验升级：

- 前端切换为 `Vue 3 + TypeScript + Vite`，使用 `Pinia` 管理全局状态
- 页面按工作区、图库、提示词库、任务、弹窗等职责拆分为组件与组合式逻辑
- 图库恢复并优化横向顺序瀑布流，左侧收起后会按可用宽度自动调整列数
- 图库补齐 `任务` 与 `提示词` 分组视图，分组采用左侧文字、右侧图片布局
- 任务名、提示词过长时会稳定截断，并保留悬停查看完整内容
- 优化图库批量选择边缘拖拽、选中显示、悬浮操作按钮等交互细节
- 引入组件库与图标库，统一下拉菜单、弹窗、设置按钮、排序图标等基础控件
- 提示词库改为左侧贴近弹窗，融合已保存提示词与内置中文提示词组
- 内置提示词按常用生成场景扩充，并支持搜索、点击添加、再次点击取消
- 清理图库分组中的旧样式残留，并完成发布前隐私扫描与文档更新

结果：

- 前端结构更适合继续维护和扩展
- 图库浏览、分组查看和批量选择更稳定
- 提示词复用效率提升，新增小功能时不再依赖旧式巨型脚本堆叠

### r 系列发布

本轮发布结构调整与体验修复：

- GitHub 自动 tag 命名从 `build.*` 改为 `r####`
- 同一流水号重发时改为 `-retry.<序号>`，避免旧格式继续累积
- 桌面版下载图片改为优先走原生保存对话框，修复点击下载无反应的问题
- 项目网页角标、桌面打包图标统一改为同一份 `logo.png`

结果：

- Release 命名和排序更稳定
- 桌面版图片下载体验恢复正常
- 网页端和桌面端图标来源统一，后续维护更简单
